# 担当箇所について
結果画⾯、サウンド＆エフェクトシステム、アイテム⽣成を担当しました。

- AwardScene : 勝敗判定以降の結果画面の進行・演出用スクリプトです。
- Effects : エフェクトデータをScriptableObjectで作成し、ゲームで使うためのスクリプトです。
- GameScene : ゲームシーンで配置するためのスクリプトです。マグロ生成、プレイヤー初期配置用スクリプトがあります。
- Sounds : サウンドデータをScriptableObjectで作成し、ゲームで使うためのスクリプトです。
